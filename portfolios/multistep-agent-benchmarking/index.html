Project Brief

Approach

Turned task definitions into reproducible benchmark workspaces with runnable assets, Jupyter/MCP-backed execution, trace capture, and grading pipelines.

This gives research teams a way to compare agent performance on realistic multistep work instead of isolated toy prompts.

Sample Task: Magnetic Susceptibility Estimation via Scanning Probe

Task QDB_6R4JQ33MR — Query

You are performing data analysis on an image collected through scanning probe magnetometry. The image shows a projection of the magnetic field gradient along the x-axis, taken in a plane above the sample, which is a microscopic metallic object of 50 nm thickness that exhibits paramagnetism. Fit the magnetic field image and estimate the unitless magnetic susceptibility χ of the object, which is constant throughout.

There is a small bias field B with unknown direction but known magnitude |B| = 35 mT, which determines both the magnetization direction and the projection vector.

Expected Answer: χ ≈ 6.9 × 10−4 (palladium, bulk value 7.66 × 10−4).
